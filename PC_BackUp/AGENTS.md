## 권위 있는 문서  <!-- [필수] -->

내용이 충돌하면 아래 순서로 판단하세요.

1. **`RULES.md`** — 코딩 규칙의 최종 권위
2. **`CLAUDE.md`** — 이 저장소의 가장 상세한 작업 지침
3. 이 파일 (`AGENTS.md`) — Codex 용 요약 및 협업 규칙
4. `docs/` 하위 문서

**문서와 실제 소스 코드가 다르면 항상 소스 코드가 맞습니다.**
오래된 문서의 "미구현" 같은 서술은 작성 시점의 스냅샷일 뿐입니다.
그것을 근거로 판단하기 전에 실제 코드를 확인하세요.

핸드오프 파일 위치는 **저장소 루트 한 곳**으로 고정합니다.

- Codex → Claude: `CODEX_TO_CLAUDE.md`
- Claude → Codex: `CLAUDE_TO_CODEX.md`

규칙:

- 다른 폴더(`docs/` 등)에 핸드오프 파일을 만들지 마세요.
- 이 파일들은 전송용 임시 파일이며 `.gitignore` 처리합니다. 커밋하지 마세요.
- 같은 이름의 파일이 여러 곳에 있으면 저장소 루트를 기준으로 삼고, 중복을 보고하세요.
- 핸드오프에 따른 소스 변경은 평소와 같이 선별 스테이징 후 커밋합니다.

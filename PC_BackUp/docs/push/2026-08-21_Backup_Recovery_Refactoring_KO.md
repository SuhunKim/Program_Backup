# 백업·복원·이력 리팩터링 변경 로그

- 작성: 2026-08-21
- 대상: 백업 생성, 복원 전 비교, 이력 XML 적용, 멤버 명명 규칙

## 요약

- 전체 백업은 ZIP 파일, 선택 폴더 백업은 날짜 기반 폴더 복사로 구분했다.
- 복원 전 현재 파일과 백업을 비교하고, 차이가 없으면 복원을 시작하지 않도록 했다.
- 이력의 XML 비교·적용은 노드가 아닌 파일 단위로 변경했다.

## 주요 변경

### 백업

- `BackupService`에서 전체 백업은 `.zip`, 선택 폴더 백업은 `_files` 폴더를 생성하도록 정리했다.
- 백업 화면과 즉시 백업 메뉴에 ZIP 저장과 폴더 복사의 차이가 보이도록 안내 문구를 수정했다.
- 이력·복원 목록의 형식 표기는 `.zip` 또는 `폴더`로 짧게 표시한다.

### 복원

- `BackupComparisonService`를 추가해 ZIP과 폴더 백업을 파일 단위로 비교한다.
- 결과는 `내용 변경`, `백업에만 있음`, `현재에만 있음`으로 분류한다.
- 텍스트 파일은 정확 비교 후 공백·탭·개행만 다른지 재확인한다.
- 차이가 없으면 복원하지 않고 화면에 안내한다.
- 비교 결과 목록과 진행률, 취소 상태를 복원 화면에 표시한다.
- 원본 안에 위치한 백업 폴더는 비교 대상에서 제외한다.

### 이력

- XML 비교는 변경된 XML 파일 하나당 한 행을 표시한다.
- 선택 적용은 해당 XML 파일 전체를 백업본으로 교체한다.
- ZIP 내부 XML 읽기는 버퍼 단위로 취소 토큰을 확인한다.
- 백업 이력이 없거나 복원 가능한 자료가 없는 날짜의 안내 문구를 보강했다.

### 명명 규칙

- 수동 작성 코드의 주요 멤버를 `m_` 접두어와 타입 약자로 변경했다.
- 디자이너 파일에서 해당 멤버를 참조하는 이름도 함께 맞췄다.

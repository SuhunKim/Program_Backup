# 복원 저널과 원상복구

- 이슈: #18
- 작성: 2026-10-19 / Codex

## 변경 내용

- 모든 복원본과 기존 파일을 확보한 뒤 파일별 쓰기 전에 영속 저널을 기록합니다.
- 중간 오류·취소는 역순으로 원본을 복구하고 새 파일을 제거합니다. 실패한 원상복구 기록은 보존합니다.
- 시작 시 미완료 저널을 확인하여 대상 잠금 아래 복구합니다. 원래 있던 추가 파일은 병합 정책에 따라 보존합니다.

## 검토 및 사용자 검증

- 소스 호출 경로와 예외·취소 경계를 검토하고 git diff --check를 수행했습니다.
- [ ] N번째 파일 잠금·취소·공간 부족에서 원본 복구 확인
- [ ] 적용 중 강제 종료 후 재실행 시 자동 복구 확인
- [ ] 원상복구 자체 실패 시 실패 경로·저널 보존 확인

## 확인하지 못한 것

빌드·실행 및 오류 주입 검증은 사용자 수행 예정입니다. 저널과 사본은 현재 사용자 LocalAppData에 있어 다른 Windows 계정으로 재실행하면 별도 수동 복구가 필요합니다. 저장장치 고장·전원 상실에 대한 파일시스템 전체 원자성을 보장하지 않습니다.

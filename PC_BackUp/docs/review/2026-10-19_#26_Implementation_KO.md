# 복원 경로의 junction·reparse point 방어

- 이슈: #26
- 작성: 2026-10-19 / Codex

## 변경 내용

- 상대 경로 경계와 예약명·경로 별칭을 검증하고 대상 루트의 모든 기존 구성요소에서 연결 경로를 거부합니다.
- 전체 복원·XML 복원·롤백과 ZIP 해제의 I/O 직전에 같은 경로 검사를 사용합니다.
- 폴더 백업 읽기·manifest 검사도 링크를 건너뛰지 않고 명시적으로 거부합니다.

## 검토 및 사용자 검증

- 소스 호출 경로와 예외·취소 경계를 검토하고 git diff --check를 수행했습니다.
- [ ] 대상 Config가 외부 junction이면 외부 파일 변경 없이 거부 확인
- [ ] 원본/백업 루트 조상의 연결 경로와 링크 파일도 거부 확인
- [ ] 일반 폴더 정상 복원과 상대 경로·예약명 거부 확인

## 확인하지 못한 것

빌드·실행 및 실제 junction 검증은 사용자 수행 예정입니다. 경로 재검사는 악의적인 다른 프로세스의 검사/사용 사이 교체를 완전히 제거하지 못합니다. 대상과 복구 작업 폴더는 신뢰할 수 있는 계정만 변경 가능하도록 권한을 관리해야 합니다.

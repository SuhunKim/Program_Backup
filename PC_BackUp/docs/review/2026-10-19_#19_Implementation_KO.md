# XML 비교 불가 상태와 namespace·혼합 텍스트 비교

- 이슈: #19
- 작성: 2026-10-19 / Codex

## 변경 내용

- 손상·빈 XML·읽기 실패를 동일함으로 숨기지 않고 파일 경로와 함께 비교 실패로 반환합니다.
- 실패 시 과거 비교 결과를 폐기하고 복원 버튼을 비활성화합니다.
- namespace URI를 키에 포함하고 혼합 텍스트·CDATA를 비교합니다. XML 크기·깊이·DTD 제한도 적용합니다.

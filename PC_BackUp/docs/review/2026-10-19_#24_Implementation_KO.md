## 변경 내용

- 압축·복사·복원 준비/적용/롤백에 버퍼 단위 파일 전송을 사용합니다. 복원 롤백은 취소되지 않도록 보호합니다.
- 백업은 바이트 기반 진행률과 검색/해시·복사/압축·검증/게시 단계를 표시합니다.
- ZIP 해제에 취소 토큰, 100,000개 항목·100GiB 총량·디스크 여유·중복/링크/경로·실제 해제 바이트 검사를 추가합니다.

## 검토 및 사용자 검증

- 소스 호출 경로와 예외·취소 경계를 검토하고 git diff --check를 수행했습니다.
- [ ] 대용량 단일 파일의 진행률과 취소 지연 측정
- [ ] ZIP 항목 수·크기·중복·필요 공간 초과 거부와 임시 폴더 정리 확인
- [ ] 취소 후 원본 복원과 정상 ZIP/폴더 백업 동작 확인

## 확인하지 못한 것

빌드·실행은 사용자 수행 예정입니다. ZIP 상한은 코드 정책이며 대형 백업 요구에 맞춰 별도 조정할 수 있습니다. 저장장치 I/O 자체가 OS에서 지연되면 토큰 확인도 지연될 수 있습니다.

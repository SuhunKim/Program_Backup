# 문자 diff의 메모리 제한과 그리기 캐시

- 이슈: #23
- 작성: 2026-10-19 / Codex

## 변경 내용

- 문자 수 곱이 100만 셀을 넘으면 LCS 행렬 대신 값 전체 변경 강조로 전환합니다. 실제 값 차이 판정은 유지합니다.
- 비교 완료 시 백그라운드에서 구간을 계산하고 두 값 셀의 재그리기에서 캐시를 재사용합니다.
- 긴 그리기 문자열은 2048자로 요약하여 MeasureText 부담을 제한합니다.

## 검토 및 사용자 검증

- 소스 호출 경로와 예외·취소 경계를 검토하고 git diff --check를 수행했습니다.
- [ ] 1만자 값에서 행렬 400MB 할당이 발생하지 않는지 메모리 측정
- [ ] 짧은 값의 문자 강조와 반복 스크롤 캐시 재사용 확인
- [ ] 긴 값의 요약 표시와 실제 복원 파일 내용 보존 확인

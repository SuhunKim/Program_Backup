# 백업 누락 방지와 명시적 작업 상태

- 이슈: #16
- 작성: 2026-10-19 / Codex

## 변경 내용

- 접근 불가·링크 항목을 조용히 누락하지 않고 실패 경로와 함께 백업을 중단합니다. 선택 백업은 선택된 루트만 탐색합니다.
- 미완성 결과는 게시하지 않는 fail-closed 정책을 사용합니다.
- Success/PartialSuccess/Canceled/Failed 상태를 추가하고 취소를 별도 반환합니다.

## 검토 및 사용자 검증

- 소스 호출 경로와 예외·취소 경계를 검토하고 git diff --check를 수행했습니다.
- [ ] 접근 거부 하위 폴더·잠긴 파일에서 실패 경로 표시 확인
- [ ] 선택 범위 밖 접근 거부 폴더가 선택 백업을 방해하지 않는지 확인
- [ ] 실패한 백업이 완료본 목록에 게시되지 않고 취소 상태가 구분되는지 확인

## 확인하지 못한 것

빌드·프로그램 실행은 저장소 지침에 따라 사용자 수행 예정입니다.

# 비동기 카탈로그와 용량 전수 탐색 제거

- 이슈: #22
- 작성: 2026-10-19 / Codex

## 변경 내용

- 대시보드·복원·이력에서 카탈로그 탐색을 백그라운드로 이동하고 최신 요청만 화면·캐시에 적용합니다.
- 새 백업의 manifest 크기를 사용하고 구버전 폴더는 반복 재귀 탐색 대신 용량 미확인으로 표시합니다.
- 합계에서 미확인 용량을 실제 0바이트와 구분합니다.

## 검토 및 사용자 검증

- 소스 호출 경로와 예외·취소 경계를 검토하고 git diff --check를 수행했습니다.
- [ ] 백업 다수 상태에서 메뉴 전환·연속 새로고침 응답성 측정
- [ ] 폴더형 구버전 용량이 미확인이고 합계에도 누락이 안내되는지 확인
- [ ] 오래 걸린 이전 조회가 최신 결과를 덮지 않는지 확인

## 확인하지 못한 것

빌드·실행 및 실제 성능 측정은 사용자 수행 예정입니다. 구버전 폴더의 용량 자동 전수 계산은 제거했으며 실제 용량이 필요하면 별도 탐색기 확인 또는 manifest 백업 재생성이 필요합니다.
